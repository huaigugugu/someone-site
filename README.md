# 有人在 · SOMEONE

一个**虚构的智能家居品牌官网**。前 90% 是一份做得很正经的 SaaS 落地页，最后 10% 会变成别的东西。

页面逻辑全在 `index.html` 里，零依赖：CSS / JS / 音效（Web Audio 实时合成）全部内联，不联网、不加载 CDN、不上报任何数据。唯一的图片资源是突脸用的 `assets/scare.jpg`。

---

## 打开

双击 `index.html` 即可。建议 Chrome / Edge / Safari 最新版。

部署到 GitHub Pages：把 `index.html` 放进仓库根目录，Settings → Pages → Branch: `main` / root，等一分钟。

---

## ⚠️ 安全提示

**页面尾部有一次突脸（jumpscare）**：`assets/scare.jpg` 全屏砸脸 + 白色闪光 + 屏幕抖动 + 合成尖叫。

| 想怎样 | 怎么做 |
|---|---|
| 不要突脸，但想看完整叙事 | 访问 `index.html?safe=1` → 跳过全屏惊吓，直接进入"已经被入侵"的结局 |
| 要画面但不要声音 | 别点左下角的 `♪ 氛围模式` —— 尖叫音效只有在声音开启时才会响 |
| 更温和的动效 | 系统里开启「减少动态效果」（`prefers-reduced-motion`）→ 图片改为淡入，不做缩放、不做闪光 |
| 想重来 | 刷新页面。结局状态只存在内存里，不写 localStorage |

**不管走哪条路，滚到底都一定会看到这张图**：走正常流程是突脸全彩满屏、然后压暗退到「我们已经进来了」后面；走 `?safe=1` 或减少动态效果，则直接从暗到亮浮出来，最后同样停在文字后面。

## 机制

整页由一个数驱动：**`D`（dread，恐惧值 0 → 1）**。

每个 `<section>` 带 `data-bg / data-fg / data-ac / data-d`，滚动时按视口中线定位当前段落并插值，把颜色和 `D` 写进 CSS 变量 `--d`。其余一切都是 `D` 的函数：

- 背景从奶油白渐变到灰褐、暗红、纯黑；暗角、扫描线、胶片噪点（canvas 实时生成）淡入
- 浏览器标签页标题被改写（`有人在 → 有人在你身后 → 让我们进来`）
- 导航文字被偷偷替换（`功能 → 感受`、`价格 → 代价`、`帮助 → 救我`、`开始使用 → 让我出去`）
- 页面上随机元素开始抖动，幅度 ∝ `D²`
- Web Audio 实时合成：4 个 triangle 振荡器做 pad + 3 个 sawtooth 低频 drone + 带通白噪声；`D` 越大越走音、越低频；`D > .84` 加入双拍心跳；静止 6.5 秒浮出一句耳语；突脸时用 `WaveShaper` 失真 + 下滑锯齿 + 噪声做尖叫（无一音频文件）

### 一些彩蛋

- **在场™ 监控**：滚进 CCTV 段落时会看到一个站在光里的人影；**第二次**滚回同一段，标签变成「你的玄关」，字幕变成「这不是演示画面」
- **权限横幅**：27 项权限，只有「全部允许」真的能点；点「管理偏好」→「没有可以管理的选项」；授权后再点它 →「不能。」
- **数字**：已连接家庭滚动到 1,240,000；成功退订 0 次；实时时钟；以及真实计时的「你已与它共处 N 秒」
- **设备识别**：用 UA 猜出你在用什么，写进「新的观看者：一台 Windows 电脑」
- **定价**：第三档「永久」的按钮 hover 会变成「已经太迟了」；`*你所在的地区不支持退订。你所在的地区是：里面。`
- **假退出**：底部「退出并删除我的数据」点三次 →「好。」→「已删除 0 项数据」
- **切走标签页**：标题变成「回来。」，切回来超过 1.5 秒会弹「欢迎回来。我们等了 N 秒。」

## 想改成自己的

| 改什么 | 在哪 |
|---|---|
| 品牌名 / 所有文案 | 直接改 HTML 里的文本节点 |
| 配色弧线 | 每个 `<section>` 的 `data-bg / data-fg / data-ac` |
| 恐怖的推进速度 | `data-d` 的取值（现在是 0 → 1，步长约 0.06） |
| 标题改写节点 | `js` 里的 `TITLES` 数组 |
| 导航被替换的时机 | 导航 `<a>` 上的 `data-swap="0.66:感受"` |
| 突脸触发点 | `frame()` 里 `np > (SAFE ? .88 : .72)` |
| 突脸图片 | 同名覆盖 `assets/scare.jpg` 即可（竖构图约 1280×1610 最省事）。这张图同时用于最后一屏的「慢慢浮现」（`object-position: 50% 3%` 控制突脸时的露脸位置，`.face` 的 `mask-image` 控制浮现时的边缘溶解） |
| 耳语 / 终端日志 / 眼睛数量 | `WHISPERS`、`LOG`、`for (let i = 0; i < 46; i++)` |
